# 开场大图

主页最上面那张"会自己动"的图，不是视频，也不是 GIF —— 它是一个 **24 秒循环的 SMIL 动画 SVG**。
没有 JavaScript、没有位图、没有一个外部请求，GitHub 直接把 `<img src>` 渲染出来。

```
hero/hero-light.svg   ← 亮色主题
hero/hero-dark.svg    ← 暗色主题（同一份代码，换一套配色）
hero/make_hero.py     ← 唯一的真相，两个 SVG 都是它生成的
```

## 改文案 / 改剧情

打开 `make_hero.py`，往下的 `EN_LINE`、`ZH_LINE`、金句、以及 `build()` 里几行 `layout(...)` 就是全部台词。
改完重新生成：

```bash
python hero/make_hero.py
```

不需要装任何依赖（Python 标准库 + 手写关键帧）。

## 分镜表（24 秒一轮）

| 时间 | 发生什么 |
|---|---|
| 0.0s | 一张普通主页，标题和正文逐字打出来 |
| 2.0s | 右边睁开一只眼睛 |
| 2.8s | 扫描线扫过全文，每行被划上高亮 |
| 4.6s | 一行英文从裂缝里掉出来：`I can't see images.` |
| 5.4s | 扫描线停在它上面，闪了两下 |
| 6.4s | 逐字翻译：英文字母往下掉，中文从下面弹起来 |
| 10.0s | 一条 Bug 虫爬进来，把「看见」两个字啃走了 |
| 12.0s | 光标变成的小人从天上砸下来 |
| 13.2s | 蓄力、起跳、竖劈 |
| 14.4s | 虫子裂成两半，粒子炸开 |
| 15.4s | 「看见」两个字飞回原位 |
| 16.8s | 眼睛眨一下，安心闭上 |
| 18.6s | 正文退场，金句浮现 |
| 23.0s | 淡出，回到开头那张白纸 |

被啃掉的是「**看见**」两个字 —— 虫子在，AI 就瞎；虫子被劈了，它才看得见你屏幕上的东西。
这就是 Vision Bridge 的全部卖点，用 24 秒演完。

## 三个坑（改的时候别踩）

1. **`keySplines` 的控制点 y 必须在 0..1 之间。** 超出范围（比如想做回弹用的 `0.2 1.6 0.35 1.0`）Chromium 会
   静默丢掉**整条**动画，元素直接停在初始值上，看起来像"没渲染"。
2. **同一个元素上不要挂两条 `animateTransform`**，后一条会覆盖前一条。要叠加就套一层 `<g>`。
   同理：元素的静态 `transform` 也会被它自己的 `animateTransform` 覆盖，别把"定位"和"动画"写在同一层。
3. **每个字都是独立的 `<text>`，宽度用 `textLength` + `lengthAdjust="spacingAndGlyphs"` 锁死。**
   这样任何操作系统上排版完全一致 —— 只有位置固定，角色才能精确地踩、砍、吃掉某一个字。

## 本地看一眼某一帧

动画是自己跑在浏览器里的。想定格在某一个时刻看细节，随便开一个 HTML 把 SVG 内联进去：

```html
<script>
  const s = document.querySelector('svg');
  s.pauseAnimations();
  s.setCurrentTime(14.4);   // 劈砍那一瞬间
</script>
```

（`--virtual-time-budget` 截图法不准，时间会飘；`setCurrentTime` 才是确定的那一帧。）
